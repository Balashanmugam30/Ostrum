## 3. Environment Variables Setup (Vercel Dashboard)
Configure the following environment variables in the Vercel Project Settings (strictly scoped to **Production**):

| Variable Name | Scope | Required / Optional | Description |
|---|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | Production, Preview | **Required** | Set to `https://theostrum.com` |
| `RESEND_API_KEY` | Production | **Required for Mail** | Server-only Resend API Key (`re_...`). Never prefix with `NEXT_PUBLIC_`. |
| `OSTRUM_ENQUIRY_TO` | Production | **Required for Mail** | Receiving mailbox address: `hello@theostrum.com` |
| `OSTRUM_ENQUIRY_FROM` | Production | **Required for Mail** | Verified sending identity: `OSTRUM Studio <notifications@theostrum.com>` |
| `NEXT_PUBLIC_OSTRUM_LINKEDIN_URL` | All Environments | Optional | Set to `https://www.linkedin.com/company/ostrum/` (hardcoded default matches this) |
| `UPSTASH_REDIS_REST_URL` | Production | Optional | Upstash Redis REST endpoint for distributed rate limiting across serverless lambdas |
| `UPSTASH_REDIS_REST_TOKEN` | Production | Optional | Upstash Redis REST bearer token |

## 4. Custom Domain & DNS Records Configuration
In your domain registrar / DNS manager (Cloudflare, Namecheap, GoDaddy):

### Apex Domain (`theostrum.com`):
- **Type:** `A`
- **Name:** `@`
- **Value:** `76.76.21.21` (or Vercel Anycast IP)
- **TTL:** `Auto` or `300`

### WWW Subdomain (`www.theostrum.com`):
- **Type:** `CNAME`
- **Name:** `www`
- **Value:** `cname.vercel-dns.com.`
- **Redirect Policy:** Configure Vercel to redirect `www.theostrum.com` to `theostrum.com` (canonical apex).

## 5. Resend Mailbox & Domain Authentication
To ensure enquiries from the website reach your inbox without bouncing or landing in spam:
1. In the **Resend Dashboard**, navigate to **Domains** -> **Add Domain**.
2. Enter `theostrum.com`.
3. Add the exact DNS verification records generated by Resend to your DNS provider:
   - `TXT` record for SPF (`v=spf1 include:amazonses.com ~all`)
   - 2x `CNAME` records for DKIM (`resend._domainkey`)
   - `MX` or `CNAME` record for Return-Path
4. Wait for domain status to display **Verified**.
5. Ensure your primary inbox provider (Google Workspace, Zoho, Microsoft 365, etc.) has its standard inbound MX records configured for `hello@theostrum.com`.

## 6. Post-Deployment Smoke Test Protocol
Immediately following live DNS propagation:
1. Load `https://theostrum.com` in desktop and mobile browsers. Verify HTTPS certificate validity.
2. Verify browser tab displays the new 3D ivory Möbius favicon.
3. Test smooth scroll navigation to `/#selected-work`, `/#capabilities`, `/#faq`, and `/#contact`.
4. Submit one synthetic test enquiry with `name="Studio Verification Test"` and `email="test@theostrum.com"`.
5. Verify the contact form responds with a clean confirmation alert and the notification email is delivered to `hello@theostrum.com`.
6. Verify `/sitemap.xml` and `/robots.txt` return HTTP 200.

## 7. Rollback Procedure
If any unexpected edge issue occurs:
1. In the Vercel Dashboard, select **Deployments**.
2. Locate the previous stable deployment (prior to release).
3. Click **Instant Rollback** to immediately route live traffic to the prior build.
4. Locally on `main`, run `git revert HEAD` and push to `origin/main` to synchronize Git history.
