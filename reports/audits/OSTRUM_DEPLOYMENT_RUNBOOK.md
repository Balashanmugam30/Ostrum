## 3. Environment Variables Setup (Vercel Dashboard)
Configure the following environment variables in Vercel Project Settings (strictly scoped to **Production**):

| Variable Name | Scope | Required / Optional | Description |
|---|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | Production, Preview | **Required** | Set to `https://theostrum.com` |
| `RESEND_API_KEY` | Production | **Required for Mail** | Server-only Resend API Key (`re_...`). Never prefix with `NEXT_PUBLIC_`. |
| `OSTRUM_ENQUIRY_TO` | Production | **Required for Mail** | Receiving mailbox address: `hello@theostrum.com` |
| `OSTRUM_ENQUIRY_FROM` | Production | **Required for Mail** | Verified sending identity: `OSTRUM Website <website@theostrum.com>` |
| `NEXT_PUBLIC_OSTRUM_LINKEDIN_URL` | All Environments | Optional | Set to `https://www.linkedin.com/company/ostrum/` |

| `UPSTASH_REDIS_REST_TOKEN` | Production | Optional | Upstash Redis REST authorization token |

## 4. Custom Domain & DNS Records Configuration
In your domain registrar / authoritative DNS manager (Cloudflare, Namecheap, GoDaddy):

### 4.1 Web Traffic Records (Pointing to Vercel)
- **Apex Domain (`theostrum.com`):**
  - Type: `A`
  - Name: `@`
  - Value: `76.76.21.21`
- **Subdomain (`www.theostrum.com`):**
  - Type: `CNAME`
  - Name: `www`
  - Value: `cname.vercel-dns.com`
- In Vercel Project Settings > Domains, add `theostrum.com` and redirect `www.theostrum.com` -> `theostrum.com`.

### 4.2 Mail Delivery Records (Resend Sending & Inbound Mail)
- Add the exact DKIM, SPF, and return-path CNAME records generated by the Resend dashboard for `theostrum.com`.
- **CRITICAL SAFEGUARD:** Do not overwrite or delete existing root MX records or mailbox SPF records when adding Resend. Resend is an outbound transactional service; inbound mail for `hello@theostrum.com` must have its own MX records pointing to Google Workspace, Zoho Mail, Proton, or your chosen email host.
