## 2. Global Clarté Principles Enforced Throughout All Sections

1. **Massive Vertical Breathing Room:** Every major chapter enforces `clamp(120px, 14vw, 200px)` vertical separation (`my-[140px]` or `py-[120px]`). No crowded, suffocating cards.
2. **Optical Serif Highlights:** Headings feature deliberate `font-serif italic` accents to create literary cadence and editorial warmth.
3. **Dual-Layer Rolling Action Buttons:** All primary call-to-actions utilize dual-layer rolling text (`.text` + `.text--clone`) and diagonal arrow translations with micro-descriptor sub-labels.
4. **Honest, Unverified-Free Copy:** Zero fabricated SLA numbers (`99.98%`), response latencies (`310ms`), student counts (`5,000`), or fake cohort labels (`Spring cohort`). Every statement is an authentic, defensible studio principle.
5. **Light-First Luminous Palette:** Warm Alabaster Linen (`#FAF7F2`), Pearl Porcelain (`#FCFAF7`), and Misty Slate (`#F3F5F7`) with Charcoal Ink (`#161514`) and Terracotta/Sage accents.
